1. Basic Structure of C Program

The 6 Core Sections

Every standard C program is divided into 6 parts. Understanding this sequence is critical.

  1. Documentation Section: To write comments (Program name, author). Compiler ignores this.
  2. Link Section: To include header files like <stdio.h>.
  3. Definition Section: To define constants using #define.
  4. Global Declaration Section: Variables declared here can be used by all functions.
  5. main() Function Section: Execution always begins here. It is mandatory.
  6. Subprogram Section: Contains user-defined functions written after main().
🎯 Exam Tip (How to write):

પ્રશ્ન પૂછાય એટલે સીધો ફકરો નથી લખવાનો. સૌથી પહેલા આ 6 નામનું લિસ્ટ (1 થી 6) પેપરની વચ્ચે લખી દેવું. ત્યારબાદ નીચે આપેલું ઉદાહરણ (કોડ) બોક્સ બનાવીને લખવું, અને છેલ્લે એ કોડની લાઈનોને વાક્યમાં સમજાવવી.

Example 1: Full Structure

// 1. Documentation Section: Program to calculate Area
// Author: Pranav

// 2. Link Section
#include <stdio.h>

// 3. Definition Section
#define PI 3.14

// 4. Global Declaration Section
float area; 

// 5. main() Function
void main() {
    int r = 5;
    area = PI * r * r;
    printf("Area is: %f", area);
}

// 6. Subprogram Section (If any custom functions are made, they go here)

2. Conditional Statements

Switch-Case Statement

Switch case is a multi-way decision-making statement. It is an alternative to a long if-else-if ladder. It tests the value of a variable against a list of case values.

🎯 Exam Tip (How to write):

સૌથી પહેલા Switch Case ની Syntax લખવી. પછી Rules લખવા (જેમ કે float ના વપરાય, break ફરજિયાત છે). અને છેલ્લે 1 ઉદાહરણ આપવું.

Example 1: Day of the week

int day = 2;
switch(day) {
    case 1:
        printf("Monday");
        break;
    case 2:
        printf("Tuesday"); // This will print
        break;
    default:
        printf("Invalid Day");
}

Example 2: Vowel or Consonant

char ch = 'A';
switch(ch) {
    case 'A':
    case 'E':
    case 'I':
    case 'O':
    case 'U':
        printf("It is a Vowel");
        break;
    default:
        printf("It is a Consonant");
}

Ternary (Conditional) Operator (?:)

It is the only operator in C that requires 3 operands. It works like a short if-else.

Syntax: Condition ? Expression_1 (If True) : Expression_2 (If False);

🎯 Exam Tip (How to write):

Syntax લખ્યા પછી, એક જ લાઈનના 2 ઉદાહરણ લખી દેવા. આ સૌથી રોકડા માર્ક્સ છે.

Example 1: Maximum of two numbers

int a = 10, b = 20, max;
// If a > b is true, max = a. Else max = b.
max = (a > b) ? a : b; 
printf("Max is: %d", max);

Example 2: Even or Odd

int num = 5;
(num % 2 == 0) ? printf("Even") : printf("Odd");

3. Loops: Entry vs Exit Controlled

Difference between while and do-while

http://googleusercontent.com/image_content/412 http://googleusercontent.com/image_content/414

Loops are used to execute a block of code repeatedly.

🎯 Exam Tip (How to write):

તફાવત (Difference) પૂછાય એટલે ફરજિયાત T-Format (ટેબલ) બનાવીને જ લખવું. છેલ્લો પોઈન્ટ બંનેની Syntax નો જ હોવો જોઈએ.

Entry Control Loop (while loop) Exit Control Loop (do-while loop)
Condition is checked before entering the loop. Condition is checked after executing the loop body.
If condition is false initially, loop will execute ZERO times. Even if condition is false initially, loop will execute at least ONE time. 
while (condition) {
    // statements
}
 
do {
    // statements
} while (condition);

Example 1: Entry Control (while)

int i = 10;
// Condition is checked first. 10 is not < 5.
// Loop will NEVER run.
while(i < 5) {
    printf("Hello");
    i++;
}

Example 2: Exit Control (do-while)

int i = 10;
// Body runs first. Prints "Hello" once.
// Then checks condition (10 < 5) which is false. Loop stops.
do {
    printf("Hello");
    i++;
} while(i < 5);

4. Functions & Recursion

What is Recursion?

Recursion is a process in which a function calls itself directly or indirectly. A recursive function must have a "Base Condition" to stop the infinite loop.

🎯 Exam Tip (How to write):

વ્યાખ્યા લખ્યા પછી એક Factorial નો પ્રોગ્રામ લખી દેવો. આ એક જ ઉદાહરણ બધે ચાલશે.

Example: Factorial using Recursion

int fact(int n) {
    // Base Condition (To stop the loop)
    if (n == 0 || n == 1) {
        return 1;
    }
    // Recursive Call (Calling itself)
    else {
        return n * fact(n - 1);
    }
}

void main() {
    printf("Factorial of 5 is: %d", fact(5));
}

5. String Handling Functions

Strings are array of characters. C provides ready-made functions to play with strings. Always include <string.h> to use them.

🎯 Exam Tip (How to write):

આ પ્રશ્નમાં 5 મુખ્ય ફંક્શનના નામ, તેનો ઉપયોગ અને 2 લાઈનનું ઉદાહરણ બુલેટ પોઈન્ટ્સમાં લખવું.

  • 1. strlen(s1) : To find the length (number of characters) of a string. 
    char name[] = "Pranav";
int len = strlen(name); // len will be 6
  • 2. strcpy(s1, s2) : To copy the content of string s2 into string s1. 
    char s1[20];
char s2[] = "VGEC";
strcpy(s1, s2); // s1 becomes "VGEC"
  • 3. strcat(s1, s2) : To concatenate (join) string s2 at the end of string s1. 
    char s1[20] = "Hello ";
char s2[] = "World";
strcat(s1, s2); // s1 becomes "Hello World"
  • 4. strcmp(s1, s2) : To compare two strings. It returns 0 if both strings are exactly the same. 
    char pass1[] = "admin123";
char pass2[] = "admin123";
if(strcmp(pass1, pass2) == 0) {
    printf("Login Successful");
}
  • 5. strrev(s1) : To reverse the given string. 
    char str[] = "C-Lang";
strrev(str); // str becomes "gnaL-C"
