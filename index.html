1. Computer Fundamentals & Algorithms

Block Diagram of Computer

Computer is made up of mainly four components:

  1. Input Section: Converts human input to computer data (Mouse, Keyboard).
  2. Central Processing Unit (CPU): The brain. Consists of:
    • ALU (Arithmetic Logic Unit): Performs math calculations and logic.
    • CU (Control Unit): Manages operations and reads instructions.
    • Primary Memory: RAM (Volatile) & ROM (Permanent). Directly accessed by CPU.
  3. Output Section: Converts 0s and 1s to human understandable info (Monitor, Printer).
  4. Secondary Memory: Hard disk, Pen drive for permanent storage.

2. C Fundamentals & Data Types

Basic Structure of C Program

There are 6 mandatory sections in a professional C program.

// 1. Documentation Section
/* Program to find Area */

3. Decision Control Structures

The switch-case Statement

It is a multi-way decision-making tool. Used when we have many choices (menu-driven programs).

🎯 Exam Tip:

યાદ રાખજો: switch માં float વેલ્યૂ ક્યારેય ના મુકાય. દરેક case પછી break; લખવું જરૂરી છે, નહિતર બધા જ કેસ રન થઇ જશે (જેને fall-through કહેવાય).

int choice = 2;
switch (choice) {
    case 1:
        printf("Option 1 Selected");
        break;
    case 2:
        printf("Option 2 Selected");
        break; // Stops execution and exits switch
    default:
        printf("Invalid Choice");
}

Conditional (Ternary) Operator (?:)

The only operator taking 3 operands. Perfect alternative for simple if-else.

Syntax: Condition ? True_Execution : False_Execution;

int a = 50, b = 20, max;
// Read as: If a > b is true, return a, else return b.
max = (a > b) ? a : b; 
printf("Maximum is: %d", max);

4. Loop Control (Entry vs Exit)

Entry Control Loop vs Exit Control Loop

This is the most frequently asked comparison. Present it exactly as a table.

Entry Control Loop (while, for) Exit Control Loop (do-while)
Condition is checked FIRST, before entering the body. Condition is checked LAST, after executing the body.
If condition is false initially, it executes ZERO times. Even if false, it is guaranteed to execute AT LEAST ONCE.
while(i < 5) { /* body */ } do { /* body */ } while(i < 5);

Break, Continue & Goto

  • break: Jumps OUT of the loop entirely. Loop stops.
  • continue: Skips ONLY the current step and forces the next iteration of the loop.
  • goto: Jumps to a specific label anywhere in the code. Avoid using it as it creates "Spaghetti code".

5. Arrays & String Handling

String Handling Functions

Strings are character arrays ending with \0 (Null). Include <string.h> to use these magic functions:

🎯 Exam Tip:

દરેક ફંક્શનની સમજૂતી આપીને આ એક-એક લાઈનનું ઉદાહરણ બેઠું લખી દેવું.

1. strlen(s1) - Find Length

Returns the total number of characters (excluding \0).

int len = strlen("Pranav"); // Returns 6
2. strcpy(s1, s2) - Copy String

Copies the contents of string s2 into string s1.

strcpy(dest, "Hello"); // dest becomes "Hello"
3. strcat(s1, s2) - Concatenate (Join)

Appends string s2 at the end of string s1.

strcat(s1, " World"); // If s1 was "Hello", it becomes "Hello World"
4. strcmp(s1, s2) - Compare

Returns 0 if both strings are exactly identical. Returns negative or positive if they differ.

if(strcmp(pass, "123") == 0) { printf("Match!"); }

6. Functions & Recursion

Elements of User Defined Function

  1. Function Declaration (Prototype): Tells compiler the return type and parameters. E.g., int sum(int, int);
  2. Function Call: Invoking the function to do its job. E.g., ans = sum(10, 20);
  3. Function Definition: The actual coding logic inside the block.

Recursion

When a function calls ITSELF inside its own body to solve smaller instances of the same problem. Must have a base case to prevent infinite loops.

🎯 Exam Tip:

Recursion નો પ્રશ્ન પૂછાય એટલે આ ફેક્ટોરિયલ (Factorial) નો પ્રોગ્રામ છાપી જ મારવો. આ સૌથી બેસ્ટ ઉદાહરણ છે.

int fact(int n) {
    // Base Condition
    if(n == 1) return 1; 
    
    // Recursive Call
    else return n * fact(n - 1); 
}

7. Pointers

What is a Pointer?

A pointer is a special variable that stores the Memory Address of another variable, instead of storing a normal value.

  • & : Address of operator. Gets the memory location.
  • * : Dereference operator. Gets the value stored AT that memory location.
int a = 10;
int *p;    // Declaration of pointer
p = &a;    // p now holds the address of a (e.g., 5000)
printf("%d", *p); // Prints 10 (value at address 5000)

Call by Value vs Call by Reference

Call by ValueCall by Reference (Using Pointers)
Passes a COPY of the actual arguments.Passes the ADDRESS (&) of actual arguments.
Changes made inside the function DO NOT affect original variables.Changes made inside the function DO affect original variables.

8. Structure vs Union

Comparison (MIMP)

Both are user-defined data types used to group different data types together. But memory management is different.

🎯 Exam Tip:

આ તફાવત પૂછાય ત્યારે ઉદાહરણમાં સાઈઝની ગણતરી (Total Bytes) બતાવવી. માર્ક્સ કપાશે જ નહિ.

Structure (struct) Union (union)
Each member gets its own separate memory space. All members SHARE the same memory space.
Size = Sum of sizes of all members. Size = Size of the largest member only.
All members can be accessed at the same time. Only one member can be accessed at a time. 
// Structure Memory: 2(int) + 4(float) + 1(char) = 7 Bytes Total Space
struct Employee {
    int id;
    float salary;
    char grade;
};

// Union Memory: 4 Bytes Total Space (Float is the largest)
union Employee {
    int id;
    float salary;
    char grade;
};

9. File Handling & Dynamic Memory Allocation (DMA)

File Handling Modes

  • r : Open for reading (Error if file doesn't exist).
  • w : Open for writing (Creates new file or overwrites existing).
  • a : Open for appending (Adds data to the end of existing file).

Dynamic Memory Allocation (DMA)

Allocating memory at runtime (while program is running) from the Heap. <stdlib.h> is required.

  • malloc() : Allocates single block of uninitialized memory.
  • calloc() : Allocates multiple blocks and initializes them to zero (0).
  • realloc() : Resizes previously allocated memory.
  • free() : Releases memory back to the system to prevent memory leaks.
