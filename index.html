1. Computer Fundamentals

Block Diagram of Computer

A computer is made up of mainly four components[cite: 11]:

  • Input Section: Converts human-understandable input to computer controllable data (e.g., Mouse, Keyboard).
  • CPU (Central Processing Unit): Known as the brain of the computer. It consists of:
    • ALU (Arithmetic Logic Unit): Performs all arithmetic calculations and logical decisions.
    • CU (Control Unit): Controls all other units and manages operations.
    • Primary Memory: RAM (volatile) and ROM (permanent). Accessed directly by CPU.
  • Output Section: Sends information to the outside world (e.g., Monitor, Printer).
  • Storage Devices: Secondary memory to store data permanently (e.g., Hard disk, Pen drive).

Algorithm & Flowchart

Flowchart: A pictorial or graphical representation of a process. Easy to understand but difficult to modify for big problems[cite: 11].

Algorithm: A finite sequence of well-defined steps for solving a problem in a systematic manner (written in English)[cite: 11].

Implicit vs Explicit Type Conversion

Implicit: C automatically converts lower data types to higher data types without losing significance[cite: 11].

Explicit: Forced conversion by the programmer using cast operator: (type-name) expression[cite: 11].

3. Decision Control Structures

if, if-else, and Nested if

These are decision-making statements. Based on the test expression, specific blocks of code execute[cite: 11].

switch-case statement

A multi-way decision-making statement used when an expression matches one of many constant values[cite: 11].

switch (grade) {
    case 'A':
        printf("Excellent");
        break;
    default:
        printf("Invalid");
}
Rules for Switch:

Float or other data types are not allowed. Case labels must be unique and constant. Break statement is optional but recommended[cite: 11].

4. Loop Control Structures

Types of Loops

  • while loop (Entry Control): Checks condition first. If false, body never executes[cite: 11].
  • for loop (Entry Control): Concise structure for(initialization; condition; increment)[cite: 11].
  • do...while loop (Exit Control): Body executes first, then condition is checked. Guaranteed to run at least once[cite: 11].

break, continue, goto

break: Provides an early exit from the innermost loop or switch[cite: 11].

continue: Skips the remaining statements in the loop body and proceeds to the next iteration[cite: 11].

goto: Jumps from one point to another labeled point in a function (generally avoided)[cite: 11].

5. Arrays & Strings

Arrays

An array is a fixed-size sequenced collection of elements of the same data type. The subscript always begins with 0[cite: 11].

int marks[5] = {50, 60, 70, 80, 90}; // 1D Array
int matrix[2][3]; // 2D Array (Rows, Columns)

6. Functions & Recursion

User Defined Functions

A block of code that performs a specific task. Has 3 parts: Declaration, Definition, and Call[cite: 11].

Call by Value vs Call by Reference

  • Call by Value: Values of actual parameters are copied. Original values in the calling function remain unchanged[cite: 11].
  • Call by Reference: The address of actual parameters is passed. Original contents can be changed by the function[cite: 11].

Recursive Function

A function that calls itself. Must have a terminating condition to avoid an infinite loop[cite: 11].

int fact(int n) {
    if(n == 1) return 1;
    else return n * fact(n-1);
}

7. Pointers

Concept

A pointer is a variable that contains the address or location of another variable[cite: 11].

  • & (Address operator): Returns memory address[cite: 11].
  • * (Dereferencing operator): Returns value stored at that address[cite: 11].
int a = 10, *p;
p = &a; // p now stores address of a

Array vs Pointer

An array name is a constant pointer to the first element of the array. a[i] is exactly the same as *(a+i)[cite: 11].

8. Structures & Unions

Structure

A collection of logically related data items of different data types grouped under a single name[cite: 11].

struct book {
    char title[100];
    float price;
} b1;

Structure vs Union

StructureUnion
Each member is assigned its own unique storage area[cite: 11].All members share the same storage area[cite: 11].
Total memory = sum of all members' memory[cite: 11].Memory = maximum memory required by the largest member[cite: 11].

10. Dynamic Memory Allocation & Storage Classes

DMA Functions

  • malloc(): Allocates uninitialized memory from heap[cite: 11].
  • calloc(): Allocates block of memory and initializes to zero[cite: 11].
  • realloc(): Reallocates memory block with a new size[cite: 11].
  • free(): Releases the allocated memory[cite: 11].

Storage Classes

Decides the scope, lifetime, and memory allocation of a variable[cite: 11]:

  • auto: Local scope, garbage default value[cite: 11].
  • register: Stored in CPU registers for fast access[cite: 11].
  • extern: Global variables accessible throughout the program[cite: 11].
  • static: Retains its value between multiple function calls[cite: 11].
