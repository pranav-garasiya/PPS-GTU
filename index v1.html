1. Computer Fundamentals & Algorithms

Characteristics & Limitations of Computer

Advantages (Characteristics):

  • Speed: Calculates millions of expressions in a fraction of a second (Micro/Nano seconds).
  • Storage: Stores huge data in Gigabytes (GB) and Terabytes (TB) safely.
  • Accuracy: Performs complex math without any human error.
  • Reliability & Automation: Works 24/7 without tiredness and automates tasks.

Limitations:

  • Lack of Intelligence (Zero IQ): Cannot think or take natural decisions.
  • Unable to Correct Mistakes: If you input wrong data, it gives wrong output (Garbage In, Garbage Out).

2. C Fundamentals & Operators

Variables & Constants

Variable: A data name used to store a value that CAN change during execution. Rules: Must start with alphabet or underscore (_), no spaces allowed, cannot use keywords.

Constant: A value that DOES NOT change. E.g., Integer (123), Real (3.14), Single Character ('A'), String ("VGEC").

Operators in Detail

Operators perform mathematical or logical operations.

  • Arithmetic: +, -, *, /, % (Modulo - gives remainder. Only for integers).
  • Relational: <, >, <=, >=, == (Check equality), != (Not equal).
  • Logical: && (AND - True if ALL true), || (OR - True if ANY one is true), ! (NOT - reverses condition).
  • Bitwise: Performs operations bit-by-bit. & (Bitwise AND), | (Bitwise OR), ^ (XOR), << (Left Shift - Multiplies by 2), >> (Right Shift - Divides by 2).
  • Assignment: =, +=, -=. (e.g., a += 5 is same as a = a + 5).

3. Control Structures

Nested if-else

When an if statement is written inside another if statement, it's called nested if. Used to check multiple dependent conditions.

int a = 10, b = 20, c = 30;
if (a > b) {
    if (a > c) printf("A is max");
    else printf("C is max");
} else {
    if (b > c) printf("B is max");
    else printf("C is max");
}

4. Loops in Full Detail

The 4 Steps of Looping

Every loop basically has 4 elements:

  1. Initialization: Setting up a starting value (e.g., i = 1).
  2. Test Condition: Checking if the loop should run (e.g., i <= 10).
  3. Loop Body: The actual code to execute (e.g., printf("%d", i);).
  4. Increment/Decrement: Updating the counter (e.g., i++).

5. Arrays & Strings Deep Dive

Initialization of Single & Multi-Dimensional Array

1D Array (Single Dimension):

  • int num[3] = {1, 5, 2}; (Initializes exactly 3 elements)
  • int num[5] = {1, 7}; (First two are 1 and 7, remaining three are auto-filled with 0)

2D Array (Matrix): Has rows and columns. data_type name[row][col];

  • int table[2][3] = {1,2,3,4,5,6};
  • int table[2][3] = {{1,2,3}, {4,5,6}}; (Proper grouping by rows)

What is a String? (The \0 Concept)

In C, a string is simply a 1D array of characters. It ALWAYS ends with a special Null character '\0'. This tells the compiler where the string ends.

char name[] = "VGEC"; 
// Memory stores: 'V', 'G', 'E', 'C', '\0' (Total 5 bytes)

6. Functions Detailed

Actual vs Formal Arguments

Actual Arguments: The variables passed inside the bracket WHEN CALLING the function. They contain the real data.

Formal Arguments: The variables declared in the function DEFINITION header. They receive the copied data.

void main() {
    int x = 10, y = 20;
    sum(x, y); // x and y are ACTUAL arguments
}

void sum(int a, int b) { // a and b are FORMAL arguments
    printf("%d", a + b);
}

7. Pointers Deep Dive

Array of Pointers

Just like an array of integers, we can create an array where every element is a pointer (storing an address). It is highly used for dynamic 2D arrays.

Syntax: data_type *array_name[size];

int *ptr[5]; // Array of 5 integer pointers
int a = 10, b = 20;
ptr[0] = &a;
ptr[1] = &b;

Swapping two values using Pointers (Call by Reference)

void swap(int *a, int *b) {
    int temp;
    temp = *a;  // Get value at address 'a'
    *a = *b;    // Put value of 'b' into 'a'
    *b = temp;  // Put temp into 'b'
}
// Call it using: swap(&x, &y);

8. Structure & File Handling

Nested Structure

A structure written inside another structure. Useful for complex data.

struct Address {
    char city[20];
    int pin;
};
struct Student {
    char name[50];
    struct Address add; // Nested Structure
};

Essential File Functions

  • fopen(filename, mode): Opens a file. Modes: "r" (read), "w" (write), "a" (append).
  • fclose(fp): Closes the file safely.
  • fprintf(fp, "..."): Writes formatted text into a file.
  • fscanf(fp, "..."): Reads formatted text from a file.
  • getc(fp): Reads a single character from the file.

9. Debugging and Testing (New Syllabus 2026)

Testing vs Debugging

Testing: Done by Testers. It is the process to check if the program meets the requirements and finds where the program fails. Basically, finding out "Is there a problem?".

Debugging: Done by Developers/Programmers. Once testing finds an error (bug), debugging is the process of analyzing the code, finding the exact line causing the issue, and FIXING it.

Unit Testing

Testing individual units or components (like a single function) of a software independently to verify they work as expected. If you write a sum() function, you test it by passing 2 and 3 and checking if the output is exactly 5.
